# experiments/

Reproducible experiment configuration and results: which router version,
provider set, and benchmark tasks were used for a given run, and what was
measured.

This is empty during project bootstrap. It is populated starting in **V0**,
with:

- `results/` — recorded output from experiment runs (cost, latency,
  evaluation scores), committed only for runs worth keeping as a reference
  point, never fabricated or hand-edited.

No experiments have been run yet — see `PROJECT_STATE.md` at the
repository root for current status.
